# Context

Code: `context/`

- **Finding the session** (Claude Code, checked on 2.1.306): the `claude` process in the pane gives its pid and `CLAUDE_CONFIG_DIR` (else `~/.claude`). `<config>/sessions/<pid>.json` gives `sessionId` and `cwd` (re-read each tick: `/clear` changes the id). The transcript is `<config>/projects/<cwd with every non-alphanumeric character as '-'; past 200 characters cut, plus '-' and a hash>/<sessionId>.jsonl`, the rule cornercase follows (`design/context-use.md` there); when the cut path does not match, the folder is found by listing `projects/` for the session's file.
- **Fixed part**: the newest `attachment` of type `instructions` lists each loaded instruction file (`CLAUDE.md`, `AGENTS.md`, imports, `MEMORY.md`) with path and full content; `skill_listing`, `deferred_tools_delta`, `mcp_instructions_delta`, `agent_listing_delta` and `prompt_snapshot` (system prompt) are the rest. These are what every turn pays.
- **Dynamic part**, since the last `system`/`compact_boundary` (what came before is no longer in the context): `tool_use` blocks joined to their `tool_result` by id, grouped by file for `Read`, `Edit`, `Write` (`input.file_path`), by command for `Bash`, by pattern for `Grep`/`Glob`, and by category for the rest (user prompts, assistant text, subagents' results, other tools). Sidechain lines (`isSidechain`) are a subagent's own context and are left out.
- **Tokens**: the real total is the last assistant reply's `usage` (`input_tokens + cache_creation_input_tokens + cache_read_input_tokens`), as cornercase computes its percentage. Each part is estimated as characters / 4, then all estimates are scaled so they add up to the real total; they show with `≈`. The `count_tokens` API was rejected for the MVP: it needs a key and network for a view that refreshes every few seconds.
- **Reading**: the transcript is read as it grows (offset kept, a quiet tick costs one `stat`); a shrunk or replaced file is read again from the start. The first read takes the whole file, since the fixed part sits at its beginning.
- The transcript is not a stable API: every record is parsed tolerantly, and a missing record makes its part `—` rather than an error. Fixtures are named by Claude Code version.
